# 结构：段落与密度分布

如果说局部设计解决的是“这一两屏怎么写好”，那么进阶结构关注的就是：**当把所有局部拼成一首完整的两分钟谱面时，各个段落的密度与难度分布是否共同支撑起了全曲的表达？**

## 全曲难度预期的锚定

在动笔规划一张谱面的全曲结构时，首先需要锚定它的整体难度预期。如基础篇所述，这一预期并非凭空设定，而是受制于曲目客观的 **BPM**、**有效音符密度**以及**曲风特征**：

- 在中慢速（如 BPM 120）铺满十六分的格局下，以锁链为主配四分、八分自然落在 8～9 级的次难度区间；若大量实采十六分并混入多声部，则可自然推升至 11～13 级。
- 在常规中高速（BPM 200 以下）曲目中，顺应音乐正常编写的主难度多分布在 14～15 级下位。

除了速度与密度，**高潮段的音乐形态**往往是决定全曲难度上限的关键锚点：

!!! important "“有气势而无密度”的高潮段"
    并非所有曲目的高潮都是靠密集的鼓点或快速的合成器音符堆砌出来的。有些曲目的高潮段主要依靠**多轨道交响叠加、悠长恢弘的长音**来烘托气势——即在听感上极具爆发力，但客观上缺乏高频密集的音头。

    面对这类“有气势而无密度”的高潮段，全曲的难度预期通常会相应下降；更重要的是，**高潮之前的铺垫段落必须有意识地压制难度**。如果前奏或主歌写得过于密集硬核，到了真正的高潮段却只能拉长音或画慢锁链，整张谱面的张力结构就会彻底失衡。

## 情绪曲线与局部难度的收放

一张结构良好的谱面，其操作难度曲线应当与音乐的情绪曲线同频共振：

- **抑制无意义的局部突刺**：有时谱师在写某一个小节时灵感迸发，写出了一段自己勉强能打、但远超当前段落预期难度的配置。此时不能只看“这段单独打起来爽不爽”，而要结合比赛或项目的难度范围、曲目整体风格，审视它是否破坏了前后的难度梯度。
- **尾杀的合理容忍度**：在对照音乐情绪控制难度曲线时，社区与玩家通常容许**“尾杀”**（曲目临近结束时的最后一段爆发）在难度上稍微高出全曲平均水平一点——但这同样需要建立在音乐结尾本身情绪推向顶峰的前提之上，且幅度应当克制。

## 相似段落的层次递进

在全曲尺度上审视重复或相似段落时，我们需要把“保持”与“变化”放进更大的时间轴里权衡：

1. **完全复现的合理性**：当音乐在后半段原样复现、配器毫无二致（或仅有极次要的背景音色变化）时，保持与前段一致的配置能够强化全曲的结构对称感与记忆点；不必为了“变化”而强行制造没有音乐依据的差异。
2. **有依据的递进设计**：当后半段的重复乐句承担了全曲情绪升华的任务（伴随升调、新主奏声部加入或鼓组律动翻倍），则应当调动采音（混 FR / 切换新轨）、键型（交互改双纵、锁链改 Click）与摆位（增大位移）形成清晰的层次递进。
3. **段落收尾的承上启下**：利用段落末尾的鼓过门（Drum Fill）果断切换采音重心，既能避免长时间停留在同一旋律轨带来的听觉与操作疲劳，又能自然地引出下一段落的密度变化。
