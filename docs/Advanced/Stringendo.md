# 配置：键型与局部设计

在[基础配置](../Qualified/Sostenuto2.md)中，我们已经确立了几条核心认知：采音与配置在落笔时共同完成；Note 类型服务于音色质感；多音色组合必须按音色分别设计；音高摆位需要在遮挡、手序与手感之间寻求妥协。

本章将从局部设计的视角出发，探讨如何把这些原则转化为富有表现力的键型组合与段落推进。

## 多音色组合的拆解与区分

当一段音乐中同时包含主旋律、切分和弦、低频 Bass 或高频点缀音时，谱师面临的首要课题就是**在同一屏内建立清晰的视觉与触觉分层**。

回顾基础篇提到的反例：两个以上音轨拼出完整十六分时，不能直接糊成一段同质化的十六分交互。为了让玩家在双手操作中直观感受到“自己正在同时演奏不同的乐器”，可以从以下维度拉开音轨之间的区分度：

- **Note 类型区分**：例如用 Hold / Drag 承载连贯的旋律或长音线条，用 Click / Flick 还原干脆的打击乐或跳音；
- **空间分区区分**：将不同音轨分配在屏幕的不同横向区间（如左半屏与右半屏、内侧与外侧），避免不同声部的 Note 混杂在同一条垂直轨迹上；
- **键型形态区分**：即便同样使用 Click，也可以通过单点、双押、微纵或斜向位移等形态差异，将主次声部的节奏型剥离开。

## 局部配置的演进与加强

当音乐在段落内部推进，或者相似乐句以更高昂的姿态重现时，局部配置需要展现出有逻辑的**发展与加强**。

结合前文提到的加强动机，我们在局部设计中常用的演进手段包括：

1. **声部叠加与重采**：当新轨道带来更高的有效密度时，通过混 FR 将新声部编织进原有骨架，或直接切换到更具冲击力的新轨道。
2. **同密度下的键型升级**：在采音时间点完全不变的前提下，通过改变键型来拉升操作张力——例如将原本平缓的交互改为**双纵**，或者将原本顺滑带过的锁链改为需要实打的 **Click**（再次提醒：一般**不推荐**单纯为了加难而把 Drag 改为 C-Drag）。
3. **空间位移的放大**：通过拉开相邻音符或音群之间的横向跨度，用更大的手部移动幅度来呼应音乐情绪的扩张。

## 音高走向与可读性的平衡

在局部设计中追求音乐表现力时，永远不能脱离 Cytus II 的双指可读性与手序逻辑：

- **半屏严格、半屏妥协**：受限于上下翻页的前后屏遮挡与左右手交替要求，很多时候我们只能在两屏之中的**其中一屏（或一半区域）**严格还原音高起伏，而在另一屏优先保证出手的顺畅与视野的干净。
- **以形态代位置**：当连续音高无法全部用 Click 逐一拉开时，不妨用**向右上/左上倾斜的交互**来暗示旋律走向，或**将旋律简化为锁链**以释放空间。
- **变速前后的形态切换**：在扫描线发生变速的交界处，切忌延续完全相同的配置形态（如跨越变速点的同形态交互），应当主动改变键型或摆位结构，帮助玩家第一时间感知速度变化。
