# 后记：到何处去

写到这里，这篇关于 Cytus II 谱面创作的教程就告一段落了。

回顾全篇，从最基础的音频对齐、BPM 测算与制谱器操作，到 Qualified 的合格标准，再到采音、配置、结构三个维度的展开，我们讨论了许多具体的处理方法、常见误区与边界情况。但如果要把所有这些零散的经验浓缩成一句话，依然是我们在初探中提出的那条核心方法论：

> **谱面响应音乐的变化，谱面的变化需要理由和自洽的内在逻辑，逻辑性优先，表达方式可以取舍。**

音乐是极为丰富的，而双指音游的画布与载体是有边界的。正因为我们永远不可能把音乐中的每一个细节毫无遗漏地直译成 Note，写谱才成为了一门**取舍的艺术**——你选择保留什么、舍弃什么、强调什么、简化什么，构成了你作为谱师对这首音乐的独特诠释。

教程中给出的所有建议、倾向与经验范围，都不是用来束缚创作的教条，而是帮助你避开前人踩过的坑、更快建立起判断坐标系的路标。当你能够清楚地说出自己每一处选轨、每一个键型、每一次变化背后的理由，并且让它们在整张谱面中自洽地运转、给玩家带来舒适而富有表现力的游玩体验时，你就已经形成属于自己的方法论了。

去多听、多打、多看、多写吧。愿你在谱面创作的旅途中，找到属于自己的表达乐趣。
