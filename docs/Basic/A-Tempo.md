# 尾声：谱面完成之后

当你放完最后一个 Note、补齐最后一段速度事件，初稿终于诞生了。但距离一张真正成熟、可以发布到社区的谱面，还有至关重要的最后一步：**复查、实机游玩测试（Playtest）与打包发布**。

## 静态复查与工具排查

在把谱面导入移动设备之前，可以先在 Cylheim 中完成一轮系统的静态与预览复查：

1. **善用编辑器内置检查与视图工具**：
   - 查看 Cylheim 侧边栏的**“谱面检查”**面板，快速排查普通音符距离过近、音符超出横向边界、Drop Click 下落轨迹重合或非法锁链连接等基础硬伤（双击问题条目即可直接跳转到对应 Tick）。需要注意，工具检查仅提供启发式提示，不能替代人工判断。
   - 按 `F7` 开启**纯 Note 查看模式**（暂时隐藏格线、扫描线与编辑 UI），或按 `F8` 打开**页面浏览**缩略图，从宏观和干净的视野检查前后屏遮挡、摆位对称性以及段落间的视觉密度分布。
   - 若项目包含多个难度，可在设置中开启**“切换谱面标签页时沿用 Tick 位置”**，在相同时间点横向对比不同难度的采音与配置梯度。
2. **0.5x 慢放与开启保持音调复查对音**：
   - 再次开启 0.5x 慢放（配合“保持音调”），重点抽查变拍变速交界处、12/24 分连音切换处以及密集段是否存在遗漏的 zure。
3. **检查事件与基础属性**：
   - 确认所有发生线速变化的位置前两拍（默认 480 Tick）都已正确生成或放置了变速提示事件，且没有在速度未变处滥用变速提示。

## 实机游玩（Playtest）与反馈迭代

在电脑屏幕上“看谱面回放”与在平板或手机上“亲手游玩”，暴露出的问题是截然不同的。

- **回放预览（如使用 Cylheim 的“在独立窗口中演示”）**适合检查视觉演出、扫描线变速提示时机以及整体的音画同步感；
- **实机游玩（Playtest）**则是检验手序是否顺畅、跨页是否存在视野遮挡、Flick 附近是否有容易误触或吃音的配置、以及局部难度是否超出预期的唯一标准。

沿着创作时的理由回看成品：如果某一段配置在实际游玩中屡屡出现手感别扭或读谱困难，不要舍不得删改——回到“逻辑性优先，表达方式可以取舍”的原则，换一种更自然、更贴合游戏表达范式的写法。

## 导出、打包与发布

当谱面经过反复打磨定稿后，就可以进入最后的打包与发布环节：

1. **检查音频与曲绘资源**：
   - 确认正式音乐与 15 秒左右的预览音频（建议加上淡入淡出）均为码率适中的 **OGG** 格式，背景图片比例与分辨率适中，且曲目不存在版权限制（可对照 [Cytoid 黑白名单](https://docs.google.com/spreadsheets/d/1tWktIWXCcCo9_qyo-TJMNVeuYrFFPL71BL0zB5ve-5U/edit#gid=0) 核实）。
2. **使用 Cylheim 导出 Cytoid 关卡包**：
   - 在 Cylheim 的 Cytoid 导出功能中填写关卡 ID、曲名、曲师、画师、谱师及来源链接等 Metadata（可直接从项目已有谱面信息中快速下拉选用），将全部难度打包导出为 `.cytoidlevel` 文件。
   - 导入 Cytoid 进行最后一次完整实机测试，确认音频起拍、预览片段、背景显示与 UI 表现均无异常。
3. **录制或导出预览视频（可选）**：
   - 如需制作谱面宣传或审谱视频，可直接使用 Cylheim 内置的**视频导出**功能（支持 MP4 / WebM / MKV 容器与标准编码预设），无需额外配置外部录屏软件即可生成高画质演示视频。
